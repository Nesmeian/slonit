# TASK: Work with strings

### Tasks:

1. Create a function that takes user data and makes the first letter of the first word of this data uppercase
2. Create a function that takes a string and if the string is longer than 40 characters, slice that string using '...',making task more complicated by slicing at a space or punctuation mark.
3. Create a function that takes two strings and returns true or false depending on whether at least one of the strings (regardless of which one) is a substring of the other string. If yes, the function should return true; otherwise, it should return false.
