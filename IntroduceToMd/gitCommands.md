###Commands

1. _git config user.name_ — This command is used to set the username that will be displayed in commits.
   _git config user.email_ — This command is used to set the email address of the user that will be displayed in commits.

2. _git add_ — is the main command for adding changes to the index.
   _git add ._ — adds all changes in the current directory.
   _git add -A_ — adds all changes in the entire project.
   _git add -u_ — adds changes only for tracked files.

3. _git status_ — This command provides information about the current state of the working directory and the staging area.
4. _git branch_ — This command is used to manage branches in a Git repository.
5. _git rm_ — This command is used to remove files from your working directory and the staging area in a Git repository.
6. _git remote_ — This command is used to manage remote repositories in Git.
7. _git push_ — This command is used to upload local repository content to a remote repository
8. _git commit_ — This command is used to save your changes to the local repository in Git
