# Task: Arrays and theirs methods

## Fundamental Topics in Any Programming Language

It is crucial to learn how to apply the methods `find`, `filter`, `reduce`, and `map` when working with arrays. There will be assignments ahead that involve working with these methods. Understanding and using these methods in code (or rather, the lack thereof) can easily reveal inexperienced developers. Therefore, familiarize yourself with them and solidify them in your knowledge stack.

For now, as assignments, you will write a few methods that perform the same functions as the existing ones.

## Assignments

1. **mySlice(arr, [start], [end])**  
   This method should perform the same function as `arr.slice([start], [end])`, but without using `arr.slice` internally.

2. **myIndexOf(arr, item, from)**  
   Implement a method similar to `arr.indexOf(item, from)`.
